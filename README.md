# 🏥 MediCare-AI: Smart Healthcare & Triage Assistant

An intelligent, conversational AI assistant designed to automate symptom triage and streamline hospital appointment bookings using Python, Flask, and Dialogflow.

---

## 🛠️ Tech Stack

* **Programming Language:** Python
* **Backend Framework:** Flask (Webhook Fulfillment API)
* **Conversational AI:** Google Dialogflow / CCAI (Contact Center AI)
* **Tools & IDE:** VS Code, Git, GitHub

---

## ✨ Key Features

* **🩺 Smart Symptom Triage:** Analyzes initial patient symptoms (fever, chest pain, cold) and suggests appropriate hospital departments.
* **📅 Automated Appointment Booking:** Schedules doctor appointments through natural conversational chat flows.
* **🚨 Emergency Routing:** Automatically detects critical symptoms like severe chest pain and alerts for emergency care.
* **⚡ Live Webhook Fulfillment:** Powered by a lightweight Python Flask backend to deliver dynamic real-time responses.
